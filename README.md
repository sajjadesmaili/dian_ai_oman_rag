

# Oman Law RAG Assistant 🇴🇲⚖️

A high-performance **Retrieval-Augmented Generation (RAG)** system designed to answer legal queries based on the **Laws of the Sultanate of Oman**.

This project leverages **Hybrid Search** — combining Dense Vector Search (FAISS + BGE-M3) and Sparse Keyword Search (BM25) — to retrieve the most relevant legal texts, then uses Large Language Models (LLMs) to generate accurate answers with **strict, verifiable citations**.

---

## 🚀 Key Features

- **Hybrid Search Engine**  
  Combines `BGE-M3` dense embeddings (FAISS) with `BM25` sparse retrieval for high-precision legal search.

- **Arabic Legal NLP**  
  Custom normalization and preprocessing tailored for Arabic legislative texts.

- **Hallucination-Free Citations**  
  Sources (Title, ID, and Link) are appended programmatically — not generated by the LLM — ensuring 100% traceability.

- **FastAPI Backend**  
  Lightweight, asynchronous API suitable for local development and production.

- **Metadata Boosting**  
  Optional score boosting based on law type, recency, or other legal metadata.

## 🛠 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/oman-law-rag.git
cd oman-law-rag
```

### 2. Install Dependencies

Using a virtual environment is strongly recommended.

```bash
pip install -r requirements.txt
```

---

## 🔐 Environment Setup

Create a `.env` file in the project root and add your OpenAI API key:

```ini
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxx
```

---

## ⚙️ Usage

### 1. Build the Index (First Run Only)

Ensure `oman_laws_final_dataset.json` is available and its path is correctly configured in `build_index.py`.

```bash
python build_index.py
```

This will generate FAISS and BM25 indexes inside the `artifacts/` directory.

---

### 2. Run the API Server

```bash
uvicorn main:app --reload
```

The API will be available at:

```
http://127.0.0.1:8000
```
